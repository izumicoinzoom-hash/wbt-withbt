ポイント：センサーは「情報を集める」、アクチュエーターは「動作を実行する」

ECU（電子制御ユニット）

  [センサー群]                    [アクチュエーター群]
  水温センサー ──┐          ┌── インジェクター
  O2センサー ───┤          ├── イグニッションコイル
  クランク角 ───┤  [ECU]  ├── ISCバルブ
  エアフロー ───┤  判断・  ├── EGRバルブ
  スロットル ───┘  制御    └── VVTソレノイド

  入力(センサー) → 演算(ECU) → 出力(アクチュエーター)
整備士のポイント：スキャンツールでセンサー値（データリスト）を読み取り、異常値を発見する

CAN通信の仕組み

  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ エンジンECU │  │ ABS ECU   │  │ メーターECU │
  └─────┬────┘  └─────┬────┘  └─────┬────┘
        │              │              │
  ══════╪══════════════╪══════════════╪══════  CAN-H
  ══════╪══════════════╪══════════════╪══════  CAN-L
        │              │              │
  ┌─────┴────┐  ┌─────┴────┐  ┌─────┴────┐
  │ AT ECU    │  │ エアバッグECU│  │ ボデーECU  │
  └──────────┘  └──────────┘  └──────────┘
  • CAN（Controller Area Network）= ECU同士がデータを共有する通信規格
  • 2本の線（CAN-H と CAN-L）で高速通信
  • 1本が断線しても通信可能（ノイズに強い）

項目正常値異常例

確認クイズ

Q1. エンジンECUにとって「入力」にあたるものはどれか？

  1. インジェクター
  2. イグニッションコイル
  3. 水温センサー
  4. ISCバルブ

正解: C. 水温センサー（センサー＝入力、アクチュエーター＝出力）

Q2. CAN通信で使用される信号線は何本か？

  1. 1本
  2. 2本
  3. 4本
  4. 8本

正解: B. 2本（CAN-HとCAN-L）

まとめ

  • センサーは車両状態の情報をECUに伝える（入力）
  • アクチュエーターはECUの指令を実行する（出力）
  • ECUはセンサー情報を基に最適な制御を判断する頭脳
  • CAN通信で複数のECU間がデータを共有（2本線・高速）
  • データリストで正常値と比較して異常を発見する

オームの法則

V = I x R

記号名前単位Bahasa
V電圧（でんあつ）ボルト [V]Tegangan
I電流（でんりゅう）アンペア [A]Arus
R抵抗（ていこう）オーム [Ω]Hambatan

例: 12V電源、抵抗4Ω → 電流 = 12÷4 = 3A

直列回路と並列回路

直列回路 (Seri)

  +──[R1]──[R2]──[R3]──+
  |                      |
 [電源 12V]             GND
  • 電流はどこでも同じ
  • R合計 = R1 + R2 + R3
  • 1つ切れると全部消える

並列回路 (Paralel)

      +──[R1]──+
      |         |
  +───┤         ├───+
  |   |         |   |
  |   +──[R2]──+   |
  |                 |
 [電源 12V]        GND
  • 電圧はどこでも同じ
  • 1/R合計 = 1/R1 + 1/R2
  • 1つ切れても他は動く

配線図（ハーネス図）の読み方

  [バッテリー 12V]
       |
    ┤F├ (30A ヒューズ)
       |
    ─/ ─ (イグニッション SW)
       |
    ┬──────────────────┬
    |                    |
  [ヘッドライト左]    [ヘッドライト右]
    |                    |
    ┴──────────────────┴
       |
      GND (アース)
読み方のコツ：電源（+）からアース（-）に向かって上から下へ追う

実務での電気回路知識

  • テスターの使い方：電圧測定は並列、電流測定は直列に接続
  • 断線チェック：導通テスト（抵抗値0Ω近く＝正常）
  • ショート発見：ヒューズが飛ぶ→配線図で該当回路を追う
  • 電圧降下テスト：接触不良を発見する手法
整備現場：「ランプが点かない」→ 電源→ヒューズ→スイッチ→バルブ→アースの順で確認

確認クイズ

Q1. 12Vの電源に6Ωの抵抗を接続した場合、流れる電流は？

  1. 0.5A
  2. 1A
  3. 2A
  4. 72A

正解: C. 2A（V=IR → I=V/R=12/6=2A）

Q2. 並列回路の特徴として正しいものは？

  1. 各抵抗に流れる電流は同じ
  2. 1つの抵抗が切れると全部消える
  3. 各抵抗にかかる電圧は同じ
  4. 合成抵抗は各抵抗の合計になる

正解: C. 各抵抗にかかる電圧は同じ

まとめ

  • オームの法則 V=IR で電圧・電流・抵抗の関係を計算できる
  • 直列回路は電流が同じ、並列回路は電圧が同じ
  • 回路図記号を覚えて配線図を上から下へ追えるようにする
  • 故障診断では電源→ヒューズ→スイッチ→負荷→アースの順に確認

ノギスの構造

Struktur Jangka Sorong (Vernier Caliper)

外側測定（外径） ┌─────────────────────────┐ │ ┌─────────┐ │ │ │本尺(mm) │ │ ├────┴─────────┴──────────┤ │ 0 10 20 30 40 50 │ │ ├─┤ │ │ │V│← バーニヤ目盛 │ │ │ │ (副尺) │ └────┴─┴──────────────────┘ ↑ スライダー 【測定できるもの】 ・外側測定（外径） ← 上のジョウ ・内側測定（内径） ← 下のジョウ ・深さ測定 ← デプスバー

ノギスの読み方

Cara Membaca Jangka Sorong

読み取り手順（3ステップ）：

  1. 本尺の値を読む → バーニヤの0線の左側の目盛り
  2. バーニヤの値を読む → 本尺の線と一致する副尺の目盛り
  3. 本尺 ＋ バーニヤ ＝ 測定値
例：本尺 = 23mm ＋ バーニヤ = 0.35mm → 測定値 = 23.35mm
最小読取値：一般的なノギスは 0.05mm

マイクロメーターの読み方

Cara Membaca Mikrometer

読み取り手順（3ステップ）：

  1. スリーブの整数部を読む（1mm刻み）
  2. スリーブの0.5mm線が見えているか確認
  3. シンブルの目盛りを読む（0.01mm刻み）
例：スリーブ = 5.5mm ＋ シンブル = 0.23mm → 測定値 = 5.73mm
最小読取値：一般的なマイクロメーターは 0.01mm

測定誤差の原因と対策

Penyebab & Pencegahan Kesalahan Pengukuran

原因対策
ゼロ点のズレ測定前にゼロ点確認・調整
汚れ・ゴミ測定面をウエスで清掃
温度変化20°Cの環境で測定（標準温度）
測定力のバラつきラチェットストップを使用
読み取りミス正面から目盛りを読む（視差防止）
実技試験：測定前のゼロ点確認は必ず行う！忘れると減点

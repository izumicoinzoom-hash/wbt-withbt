バッテリーの基礎

容量表示

  • Ah（アンペアアワー）
    電気を蓄える量
    例: 60Ah = 1Aで60時間
  • CCA（コールドクランキングアンペア）
    -18℃で始動できる電流値
    寒冷地では重要

型式の読み方

55B24L

  • 55 = 性能ランク
  • B = サイズ区分
  • 24 = 長さ（cm）
  • L = 端子位置（左）

始動回路（スターター）

  [バッテリー +12V]
       |
       ├──→ [イグニッションSW] ──→ [スターターリレー]
       |                                    |
       └──────────────────→ [スターターモーター]
                                            |
                                     [フライホイール/リングギヤ]
                                            |
                                     エンジン始動！
仕組み：キーを回す → リレーがON → 大電流がスターターへ → ピニオンギヤがリングギヤと噛み合い → エンジンを回す

充電回路（オルタネーター）

  [エンジン回転] ─ベルト駆動→ [オルタネーター]
                                    |
                              [レギュレーター]
                              (電圧を13.5〜14.5Vに制御)
                                    |
                              [バッテリーへ充電]
点検項目正常値異常時
充電電圧13.5〜14.5Vバッテリー上がり/過充電
ベルト張力適正たわみ量異音・充電不良
B端子電流定格出力以下オルタネーター故障

バッテリー点検の実務

  1. 外観確認：端子の腐食・液漏れ・膨張がないか
  2. 電圧測定：無負荷時 12.4V以上（テスターで測定）
  3. 比重確認：1.26〜1.28が正常（比重計使用）
  4. 負荷テスト：大電流を流して電圧降下を確認
  5. 端子清掃：ワイヤーブラシで腐食を除去
注意：バッテリーから水素ガスが発生→火気厳禁！
Perhatian: Gas hidrogen keluar dari baterai → Dilarang menyalakan api!

確認クイズ

Q1. オルタネーターの正常な充電電圧はどれか？

  1. 10.0〜11.0V
  2. 12.0〜12.6V
  3. 13.5〜14.5V
  4. 16.0〜17.0V

正解: C. 13.5〜14.5V

Q2. バッテリー型式「55B24L」のLは何を示すか？

  1. 容量のランク
  2. バッテリーの長さ
  3. 端子の位置（左）
  4. 電圧の種類

正解: C. 端子の位置（左）

まとめ

  • バッテリーはAh（容量）とCCA（始動性能）で選定する
  • 始動回路：キー→リレー→スターター→エンジン回転
  • 充電回路：エンジン→オルタネーター→レギュレーター→バッテリー
  • 充電電圧の正常値は13.5〜14.5V
  • バッテリー点検は外観・電圧・比重・負荷テストで総合判断

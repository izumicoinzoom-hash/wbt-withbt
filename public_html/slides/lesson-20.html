今回は故障診断の基礎を学びます

OBD-IIとは

OBD-II概要

  • On-Board Diagnostics II
  • 車載自己診断システム
  • 排出ガス関連の異常を検知
  • 国際標準規格
  • 2006年以降の国産車は義務化

DLC（診断コネクター）

  • 16ピンの台形コネクター
  • 運転席足元付近に設置
  • スキャンツールを接続する場所
  • 全車共通の形状

DTC（故障コード）の読み方

P0301

位置値意味
1文字目Pパワートレイン（B=ボデー, C=シャシ, U=通信）
2文字目0国際共通コード（1=メーカー固有）
3文字目3サブシステム（3=点火系）
4-5文字目01具体的な故障（01=1番シリンダー）
P0301 = 1番シリンダーの失火（ミスファイア）

よく出るDTCコード例

コード内容考えられる原因
P0100エアフローセンサー異常センサー故障・配線断線
P0115水温センサー異常センサー故障・コネクター接触不良
P0300ランダム失火検出点火プラグ・コイル・燃料系
P0420触媒効率低下触媒劣化・O2センサー
P0500車速センサー異常センサー故障・配線
C0200車輪速センサー異常ABS関連・センサー汚れ
U0100ECU間通信喪失CAN通信線の断線・ショート
試験対策：Pコードの3文字目でサブシステムが分かる！

データリストの活用

診断例：エンジン不調

  DTC: P0115（水温センサー異常）

  【データリスト確認】
  ┌────────────────┬──────────┬──────────┐
  │ 項目           │ 表示値    │ 正常値    │
  ├────────────────┼──────────┼──────────┤
  │ 水温           │ -40℃     │ 80〜95℃  │  ← 異常！
  │ エンジン回転   │ 1200rpm  │ 700rpm   │  ← 高い
  │ 噴射時間       │ 4.5ms    │ 2.5ms    │  ← 長い
  └────────────────┴──────────┴──────────┘

  → 水温が-40℃（最小値）＝断線の可能性
  → ECUが「冷間」と判断し燃料を増量している
  → 水温センサーの配線・コネクター・センサー本体を点検

確認クイズ

Q1. DTC「P0301」の最初の「P」は何を意味するか？

  1. ボデー系
  2. シャシ系
  3. パワートレイン系
  4. 通信系

正解: C. パワートレイン系

Q2. 診断フローの正しい順序はどれか？

  1. 修理 → DTC読取 → 症状確認 → 記録
  2. 症状確認 → DTC読取 → 原因特定 → 修理 → 再発確認
  3. DTC消去 → 修理 → 症状確認 → 記録
  4. 原因特定 → 症状確認 → 修理 → DTC読取

正解: B. 症状確認 → DTC読取 → 原因特定 → 修理 → 再発確認

まとめ

  • OBD-IIは車載自己診断システム、DLCに接続して診断
  • DTCは5桁のコード（P/B/C/U + 数字4桁）で故障内容を示す
  • 診断フロー：症状確認→DTC読取→データ確認→原因特定→修理→消去・再確認→記録
  • データリストで正常値と比較し異常箇所を絞り込む

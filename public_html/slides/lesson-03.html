「特定整備」とは？

Apa itu "Perawatan Khusus" (Tokutei Seibi)?

定義：自動車の走行装置・制動装置・緩衝装置・自動運行装置に関わる整備

従来の「分解整備」＋ 新たに追加された整備：

  • エンジン・ブレーキなどの分解を伴う整備（従来通り）
  • エーミング（カメラ・センサーの調整）← 新規追加
  • OBD検査関連の整備 ← 新規追加

認証工場 vs 指定工場

Bengkel Bersertifikat vs Bengkel Ditunjuk

┌──────────────────┐ ┌──────────────────┐ │ 認証工場 │ │ 指定工場 │ │ (Bengkel │ │ (Bengkel │ │ Bersertifikat) │ │ Ditunjuk) │ ├──────────────────┤ ├──────────────────┤ │ ・整備のみ可能 │ │ ・整備＋検査可能 │ │ ・車検は運輸支局 │ │ ・自社で車検完結 │ │ に持ち込み │ │ ・完成検査員が必要│ │ ・規模：小〜中 │ │ ・規模：中〜大 │ └──────────────────┘ └──────────────────┘

指定工場 = 民間車検場とも呼ばれる

定期点検の法的義務

Kewajiban Hukum Inspeksi Berkala

点検種類頻度根拠条文
12ヶ月点検1年ごと法第48条
24ヶ月点検2年ごと（車検時）法第48条
日常点検運行前法第47条の2
注意：12ヶ月点検は車検と別！使用者の義務として実施が必要

整備記録の管理

Pengelolaan Catatan Perawatan

記載が必要な項目：

  • 点検・整備の実施日
  • 実施した作業内容の詳細
  • 走行距離（オドメーターの値）
  • 整備した部品・部位
保存期間：2年間の保存義務（整備工場側）
試験頻出：「記録の保存期間は？」→ 2年

エーミングとOBD検査

Kalibrasi Sensor & Inspeksi OBD

エーミング（Aiming / Kalibrasi）：

  • 自動ブレーキのカメラ・センサーの角度調整
  • フロントガラス交換後に必須
  • 特定整備に該当 → 認証が必要

OBD検査：

  • 車のコンピュータに接続して故障コードを確認
  • 2024年10月〜新車から段階的に導入
  • 車検時の検査項目に追加

まとめ ／ Ringkasan

  1. 特定整備 = 従来の分解整備 ＋ エーミング・OBD関連
  2. 指定工場は自社で車検完結、認証工場は整備のみ
  3. 整備記録は2年間保存義務がある

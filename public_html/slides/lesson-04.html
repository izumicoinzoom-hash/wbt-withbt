整備主任者とは？

Apa itu Kepala Mekanik (Seibi Shunin)?

定義：認証工場において、分解整備（特定整備）の作業管理と品質確認を行う責任者

選任要件：

  • 2級以上の自動車整備士資格を持つこと
  • 事業場ごとに1名以上選任する義務
  • 地方運輸局長への届出が必要

整備主任者の業務内容

Tugas Kepala Mekanik

┌────────────────────────────────────┐ │ 整備主任者の3つの業務 │ ├────────────────────────────────────┤ │ │ │ 1. 作業の監督・指示 │ │ → 整備作業の品質を管理 │ │ │ │ 2. 整備記録の管理 │ │ → 記録の作成・保存を確認 │ │ │ │ 3. 保安基準適合の確認 │ │ → 整備後、基準に適合するか確認 │ │ │ └────────────────────────────────────┘

不正改造の禁止

Larangan Modifikasi Ilegal

不正改造の例：

  • マフラーの取り外し・騒音基準を超える改造
  • ヘッドライトの色・明るさを保安基準外に変更
  • 車高を基準値以下に下げる改造
  • 排ガス装置（触媒等）の取り外し
罰則：不正改造を行った者 → 6ヶ月以下の懲役または30万円以下の罰金
整備事業者が関与 → 認証取消の可能性

コンプライアンスとは？

Apa itu Kepatuhan Hukum (Compliance)?

  • 法令や規則を守ること（法令遵守）
  • 社会のルールや倫理に従って行動すること
  • 整備業では保安基準の遵守が基本
実務での心構え：
  • 「お客様に頼まれたから」は違法行為の理由にならない
  • 不正改造の依頼 → 断る義務がある
  • 問題を発見したら → 速やかに報告

監督義務と記録管理の実務

Kewajiban Pengawasan & Pengelolaan Catatan

整備主任者が確認すべきポイント：

  • 作業者が正しい手順で作業しているか
  • 使用部品は保安基準に適合しているか
  • 整備記録簿に漏れなく記載されているか
  • 記録の保存期間（2年）が守られているか
記録の保持期間（試験頻出）：
整備記録 → 2年間保存 ／ 点検整備記録簿 → 使用者が2年間保管

まとめ ／ Ringkasan

  1. 整備主任者は2級以上の資格が必要、事業場ごとに1名以上選任
  2. 不正改造は厳しい罰則あり。依頼されても断る義務がある
  3. コンプライアンス = 法令遵守は整備士の基本姿勢
